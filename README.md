## FC NOVA — Mobile Football

A playable browser football game inspired by the squad-building and match flow of mobile football titles. It is an original project with fictional clubs, players, kits, and branding.

- 11v11 matches with a pseudo-3D canvas pitch, AI teammates and opponents, four difficulty levels, halves, restarts, and a full-time report.
- Quick Match and the three-round Nova Cup knockout tournament.
- Squad management with three formations, automatic line-ups, player details, and position pickers.
- Card packs with an animated reveal, daily coin rewards, achievements, and a persistent local save.
- Vietnamese UI, mobile touch controls, and keyboard support.

### Run locally

Serve the folder with any static file server, then open `index.html`:

```bash
python3 -m http.server 8080
```

No build step or runtime dependency is required. The Barlow fonts are bundled locally.

### Controls

- Move: on-screen joystick / `WASD` or arrow keys
- Pass or switch player: `CHUYỀN` / `J`
- Shoot (hold to charge): `SÚT` / `K`
- Sprint: `TỐC ĐỘ` / `Shift`
- Tackle: `CƯỚP` / `L`
- Pause: pause button / `Esc`
